# Mobile Booking App

Ứng dụng mobile đặt lịch khám bệnh.

## Tech Stack
- Flutter (Mobile)
- NodeJS + Express (Backend)
- MongoDB

## Run Backend
cd backend
npm install
npm start

## Run Mobile
cd mobile
flutter pub get
flutter run
